# Legendary Archer 3D

Самодостаточная 3D-игра в одном файле `index.html` (Three.js r128 встроен, модели — base64 data URI, звук — Web Audio).
Откройте `index.html` в браузере на ПК, Android или iPhone — интернет не нужен.

Режимы: Тренировка, Охота, Арена (4 волны + босс), Выживание, Приключение (4 задания), Турнир (90 с).
Управление ПК: WASD, мышь, ЛКМ — натянуть/выстрел, ПКМ — прицел, Shift — бег, Пробел — прыжок, X — присесть,
R — перезарядка, C — камера, колесо — зум, 1/2/3 — стрелы, Q — оружие, V — погода, F — полный экран, Esc — меню.
